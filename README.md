# rag-practice

A hands-on learning repository for Retrieval-Augmented Generation (RAG), built from information-retrieval fundamentals to advanced and agentic RAG systems.

## Learning contract

- Learn the mechanism before hiding it behind a framework.
- Implement incrementally and reuse small, explicit primitives.
- Keep comparable experiments on shared datasets/benchmarks.
- Trace the full pipeline so failures can be attributed to retrieval, ranking, context construction, or generation.
- **Every milestone and lab must include evaluation.** A lab is not complete because it runs; it is complete only when it has a baseline, metrics, benchmark results, and written findings.

See [ROADMAP.md](ROADMAP.md) for the source-of-truth learning plan, milestone order, and Definition of Done.
